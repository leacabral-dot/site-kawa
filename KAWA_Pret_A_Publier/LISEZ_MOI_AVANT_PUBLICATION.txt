GUIDE SIMPLE (SUR MAC)
---------------------
1) Ouvrez https://github.com/new et créez un dépôt nommé kawa-site.
2) Décompressez le ZIP puis glissez les fichiers du dossier KAWA_Pret_A_Publier
   dans GitHub > Add file > Upload files. Gardez la structure des dossiers !
3) Confirmez avec Commit changes.
4) Ouvrez https://app.netlify.com , connectez GitHub, sélectionnez le dépôt kawa-site.
5) Vérifiez dans les réglages du déploiement que Publish directory = website.
   Aucune commande de build n'est nécessaire.
6) Une fois le site créé, allez dans Project configuration > Environment variables.
   Ajoutez une variable GEMINI_API_KEY contenant votre clé Gemini personnelle.
   Ne partagez jamais cette clé et ne la mettez jamais dans GitHub ou index.html.
7) Dans Netlify > Deploys > Trigger deploy : publiez une nouvelle version.
8) Visitez votre lien https://<nom-du-site>.netlify.app et ouvrez KAWI.
   Pour vérifier la configuration, visitez https://<nom-du-site>.netlify.app/api/health
   et cherchez ai_enabled: true. Cela indique que la clé est présente, pas forcément valide.
9) Posez une question originale à KAWI ; vérifiez qu'il répond librement.
